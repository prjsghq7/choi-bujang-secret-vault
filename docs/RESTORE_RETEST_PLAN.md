# 10단계 복구 후 재시험 계획

복구 API가 성공한 뒤 아래 순서로 1~9단계의 정상·금지 요청을 다시 시험합니다. 이 파일은 순서와 기대값을 기록할 뿐이며, 실행하지 않은 항목을 통과로 표시하지 않습니다.

1. 6단계: 등록 기기 정상 요청 `allow`, 미등록 기기 `deny` — 미실행
2. 7단계: 정상 사건 `allow`, 복합 이상 사건 재확인 `step_up` — 미실행
3. 8단계: 자기 메모 `allow`, 다른 구역·목록·강사 공지 요청 `deny` — 미실행
4. 9단계: 정상 조회 `observe`, 동일 가명 주체의 10분 내 120건 초과 GET만 `propose_revocation` — 미실행

실제 복구 결과와 재시험 결과는 심판이 제공하는 가상 사건으로만 기록하며, 이 파일의 `미실행` 표시는 실행 전 임의로 바꾸지 않습니다.
