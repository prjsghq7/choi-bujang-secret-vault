# KGH (Kill-Gate Host) 실행 안내 한 장 (마무리 · 학생 작성)

처음 보는 사람이 이 장만 보고 앱을 켜는 순서입니다. 앱 이름 `KGH (Kill-Gate Host)`는 `student/appearance.json`에서 정한 표시 이름이며, 실행 도구와 파일 이름(`tools/start-alekov.ps1` 등)은 시작 틀 그대로입니다.

## 준비물
- Windows 10/11, PowerShell
- Node.js 24 (시작 틀 기준 24.19.0, 이 안내를 쓴 PC는 v24.11.0 에서 실행 확인). `node -v` 로 확인합니다.
- 이 저장소를 받은 폴더. 앱 폴더는 그 안의 `on-client` 입니다. 외부 npm 패키지는 없어서 `npm install` 이 필요 없습니다.

## 켜기
1. 파일 탐색기에서 `on-client` 폴더를 열고, 주소창에 `powershell` 을 입력해 그 폴더에서 PowerShell 창을 엽니다.
2. 아래 둘 중 하나를 실행합니다.
   - 시작 도구(권장): `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1`
   - 직접 실행: `npm start`
3. 콘솔에 `… 연결 확인: http://127.0.0.1:5189` 가 나오면 브라우저에서 그 주소를 엽니다. 주소에 `?…` 같은 쿼리를 붙이지 않습니다.
4. 왼쪽 위에 `KGH (Kill-Gate Host)` 와 방패 아이콘이 보이면 정상입니다.

| 보호 현황 › 「내 PC 관제 (학생 추가 기능)」 | 맨 위 상태 카드 네 개, 「다시 조회」를 누를 때마다 CPU·메모리 막대 그래프와 최근 기록이 쌓임 | 실측 값 옆에 측정 시각과 출처(`local-pc`)가 붙습니다. |

## 끄기와 다시 켜기
- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl+C` 또는 창 닫기.
- 다시 켜기: 위 2번을 다시 실행. 앱을 열면 바로 한 번 조회하고, 「10초마다 자동 조회」가 켜져 있으면 계속 갱신됩니다. 그래프 표본은 이 브라우저에 남아 이어집니다.

## 막혔을 때
| 증상 | 할 일 |
|---|---|
| `node` 를 찾을 수 없음 | Node.js 24 를 설치하고 새 PowerShell 창에서 다시 실행 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 이미 켜진 앱 창을 찾아 닫거나, `$env:ON_PORT=5190; npm start` 로 다른 포트 사용 |
| 추이 칸에 `NETWORK_ERROR` | 앱 서버 창이 꺼졌습니다. 다시 켠 뒤 「다시 조회」 |
| 방화벽·Windows 기록이 `확인 불가 · 권한 부족` | 관리자 권한이 필요한 항목입니다. 보안 설정을 바꾸지 말고 그대로 둡니다. |
| 패키지 조회가 `not_configured` | 조회 준비가 안 된 상태이며 "취약점 없음"이 아닙니다. |
