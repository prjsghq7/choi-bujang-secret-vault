# 완성 기록 (마무리 · 학생 작성)

## 1. 기본 정보
- 과정명: 2026 KIT K-뉴딜 SKT ALEPH 공동 방어전
- 앱 이름: KGH (Kill-Gate Host) — `student/appearance.json` 의 `appName`
- 시작 틀: alekov-client-starter 0.2.21 (0.2.11 에서 공식 ZIP 으로 업데이트, 파일별 SHA-256 을 업데이트 도구의 고정 목록과 대조)
- 화면 틀·포장: 관제 대시보드형(`dashboardPreset: student-first`) · 포장 없이 내 PC 에서 실행(`npm run package-app` 미실행)

## 2. 고른 핵심 기능 3개
### 핵심 기능 1 — 내 PC 상태 추이 비교
- 제공된 부분: 「내 PC 상태」 카드와 읽기 전용 조회 `GET /api/pc/status`(`src/pc-status.mjs`, `public/pc-status-view.mjs`).
- 내가 직접 개선한 부분: `student/extension.mjs` 의 `renderStatus` 안 추이 칸. 버튼을 누를 때만 조회하고 최근 표본 5개를 메모리에 두어 CPU·메모리·디스크의 직전 대비 변화(▲▼ %p)를 보여 줌. 측정 시각·출처·단위 표시, 메모리 90% 이상·디스크 10% 미만 주의, 늦게 도착한 오래된 응답 무시, 조회 중 버튼 잠금과 `aria-busy`, 결과 영역 `role=status`, 다시 그린 뒤 버튼 초점 복원.
- 실제 확인 결과: 확인함(2026-10-29, 작성자 PC). 두 번 조회해 CPU ▼6.9%p, 메모리 ▲0.4%p, 디스크 변화 없음이 표시됨.
- 잘못된 입력이나 연결 실패 때의 동작: 확인함. 서버를 끄고 누르면 `NETWORK_ERROR` 와 다음 할 일, 이전 값에 「마지막 성공 표본」 표시. 일부 확인 불가·`NOT_ALLOWED`·계약과 다른 응답·오래된 응답은 모의 점검으로만 확인.
- 근거: `docs/student-checks/mock-pc-trend.mjs`(합성 값 8가지 경우), 이 문서 3절.

### 핵심 기능 2 — 보호 현황 표시(13·16단계)
- 제공된 부분: 자료 조회·화면 틀(`public/app.js`).
- 내가 직접 개선한 부분: `renderIdentity`, `renderStatus`(13·16단계). 연결 실패를 정상처럼 보이지 않게 `확인 불가`·`⚠ 주의`와 자료 출처를 함께 표시.
- 실제 확인 결과: 연결 없음 상태에서 확인함. 로그인·기기·세션이 `확인 불가(요청 실패)`, 자료 출처 `연결 없음`.
- 잘못된 입력이나 연결 실패 때의 동작: 위와 같음. SDP 실제 연결 상태의 표시는 미확인(학생에게 인증서가 발급되지 않음).
- 근거: 13·16단계 판정 기록(포털), `docs/STUDENT_RUNBOOK.md`.

### 핵심 기능 3 — 설치 패키지 취약점 조회(20단계)
- 제공된 부분: `GET /api/vulnerabilities` 와 OSV 대조 서버 코드.
- 내가 직접 개선한 부분: `renderVulnerabilities`(20단계). 미조회·실패·확인 불가를 "취약점 없음"으로 보이지 않게 함.
- 실제 확인 결과: 작성자 PC 에서 `not_configured`(`PROJECT_NOT_CONFIGURED`)로 표시되고 "취약점 없음이 아닙니다" 안내가 나옴. 실제 OSV 대조 결과는 미확인.
- 잘못된 입력이나 연결 실패 때의 동작: 모의 점검으로 확인(`docs/student-checks/mock-s20.mjs`).
- 근거: 20단계 판정 기록(포털).

## 3. 값의 종류 구분
- 실제 조회: 「내 PC 상태」·「추이 비교」의 CPU·메모리·디스크·네트워크 개수·방화벽 프로필·Windows 경고/오류 건수. 출처 `local-pc`, 화면에 측정 시각 표시. 이 PC 에서 2026-10-29 16:27 예: CPU 22.6%→15.7%, 메모리 95.8%→96.2%, 디스크 여유 23.4%, 방화벽 세 프로필 켜짐, 경고 39·오류 26건.
- 설명용 예시: `npm run demo` 의 예제 자료, `docs/student-checks/*.mjs` 의 합성 값. 화면에서는 `예제 자료`로 구분됩니다.
- 미연결: SDP(로그인·기기·세션·업무 앱·보안 기록), 앱 안 AI 연결.
- 확인 불가: 권한이 필요한 방화벽·Windows 기록을 읽지 못할 때, 패키지 조회 준비 미완료.

## 4. 같은 최종 소스, 다시 실행한 기록
- 실행 환경: Windows 11 Home, Node.js v24.11.0, Windows PowerShell 5.1
- 최종 커밋: 제출 직전에 `git rev-parse HEAD` 로 확인해 포털 제출 칸에 적습니다(이 문서를 담은 커밋 이후 값이므로 여기에는 적지 않음).
- 포장: 하지 않음(과정 안내).
- 새 폴더 재현: 22단계 기록(`docs/STUDENT_RELEASE_RECORD.md`) 이후 마무리 변경은 새 폴더에서 다시 재현하지 않음(미확인).

## 5. 다른 사람의 첫 사용
- 다른 사람의 첫 사용 관찰 여부: 미실시
- 막힌 위치: 미확인
- 내가 보완한 것: 실행 안내 한 장(`docs/STUDENT_RUN_ONE_PAGE.md`) 작성
- 다른 사람이 보완 뒤 다시 따라 해 본 결과: 미실시
- 내가 직접 보완 뒤 다시 실행한 결과: `npm start` 로 다시 켜서 추이 비교까지 확인함

## 6. 받은 도움과 내 선택
- AI 에게 받은 도움: Claude Code 가 시작 틀 업데이트, 추이 비교 코드, 모의 점검, 이 문서 초안을 작성. 앱 이름은 학생이 골랐음.
